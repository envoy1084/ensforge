# Erc721

Shared contract definition for Erc721.

## Import

```ts
import { erc721Abi } from "@ensforge/contracts/shared";
```

## Usage

```ts
import { getContract } from "viem";

const contract = getContract({
  address,
  abi: erc721Abi,
  client: publicClient,
});
```

## Exports

| Export      | Description                                             |
| ----------- | ------------------------------------------------------- |
| `erc721Abi` | Immutable ABI value with viem-compatible literal types. |

## Entrypoint

`@ensforge/contracts/shared`

The values are immutable and can be passed directly to viem contract, log, and encoding utilities.
