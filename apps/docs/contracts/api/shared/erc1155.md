# Erc1155

Shared contract definition for Erc1155.

## Import

```ts
import { erc1155Abi } from "@ensforge/contracts/shared";
```

## Usage

```ts
import { getContract } from "viem";

const contract = getContract({
  address,
  abi: erc1155Abi,
  client: publicClient,
});
```

## Exports

| Export       | Description                                             |
| ------------ | ------------------------------------------------------- |
| `erc1155Abi` | Immutable ABI value with viem-compatible literal types. |

## Entrypoint

`@ensforge/contracts/shared`

The values are immutable and can be passed directly to viem contract, log, and encoding utilities.
