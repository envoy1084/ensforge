# useWriteTarget

Hook for fetching write target.

## Import

```tsx
import { useWriteTarget } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useWriteTarget } from "@ensforge/react";

function Component() {
  const result = useWriteTarget({
    name: "example.eth",
    operation: {},
  });

  return <pre>{JSON.stringify(result.data, null, 2)}</pre>;
}
```

## Parameters

```ts
import type { UseEnsAtomParameters } from "@ensforge/react";
import type { GetWriteTargetParameters } from "@ensforge/sdk/capabilities";
```

### name

`string`

ENS name used by the operation. ensforge normalizes it before creating the query key or interacting with a contract.

### blockNumber

`bigint | undefined`

Block number to read from. Cannot be combined with `blockTag`.

### blockTag

`"latest" | "earliest" | "pending" | "safe" | "finalized" | undefined`

Named block state to read from. Cannot be combined with `blockNumber`.

### operation

`WriteOperation`

Value used for `operation` by this operation.

## Suspense

Use `useWriteTargetSuspense` when the read belongs beneath React [Suspense](https://react.dev/reference/react/Suspense) and an error boundary. It starts immediately, suspends during the initial load, and throws typed failures to the nearest error boundary.

### Import

```tsx
import { useWriteTargetSuspense } from "@ensforge/react";
```

### Usage

:::code-group

```tsx [component.tsx]
import { useWriteTargetSuspense } from "@ensforge/react";

function Component() {
  const result = useWriteTargetSuspense({
    name: "example.eth",
    operation: {},
  });

  return <pre>{JSON.stringify(result.data, null, 2)}</pre>;
}
```
