# Verifiable Factory

Focused, tree-shakable ABI fragments for Verifiable Factory.

## Import

```ts
import {
  verifiableFactoryV2DeployProxyAbi,
  verifiableFactoryV2VerifyContractAbi,
} from "@ensforge/contracts/v2";
```

## Usage

:::code-group

```ts [contract.ts]

  address,
  abi: verifiableFactoryV2DeployProxyAbi,
  client: publicClient,
```
