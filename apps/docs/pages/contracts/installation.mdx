# Installation

:::code-group

```sh [pnpm]
pnpm add @ensforge/contracts viem
```

```sh [npm]
npm install @ensforge/contracts viem
```

```sh [yarn]
yarn add @ensforge/contracts viem
```

```sh [bun]
bun add @ensforge/contracts viem
```

:::

Import from the focused entrypoint that owns the definition: `deployments`, `resolver-profiles`,
`shared`, `v1`, or `v2`.
