# getResolversForAddress

Lists ENSv2 resolvers owned by an address.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]

const result = await sdk.indexer.getResolversForAddress({
  address: "0x0000000000000000000000000000000000000000",
  pageSize: 20,
});
```
