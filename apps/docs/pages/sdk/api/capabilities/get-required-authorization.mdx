# getRequiredAuthorization

Gets required authorization for capability and authorization discovery.

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Parameters

```ts
import type { GetRequiredAuthorizationParameters } from "@ensforge/sdk/capabilities";
```

### name

`string`

ENS name to operate on. ensforge normalizes it before hashing or contract interaction.

### blockNumber

`bigint | undefined`

Block number to read from. Cannot be combined with `blockTag`.

### blockTag

`"latest" | "earliest" | "pending" | "safe" | "finalized" | undefined`

Named block state to read from. Cannot be combined with `blockNumber`.

### account

`EthereumAddress`

Account used to authorize this operation. Defaults to the account exposed by the resolved wallet client.

### operation

`WriteOperation`

Value used for `operation` by this method.
