# setDnsRecords

Sets dns records for DNS and DNSSEC.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]

  name: "example.eth",
  data: "0x",

```
