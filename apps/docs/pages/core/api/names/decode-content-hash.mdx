# decodeContentHash

Decodes resolver content-hash bytes.

## Import

```ts
import { decodeContentHash } from "@ensforge/core";
```

## Usage

```ts
const decoded = decodeContentHash(contentHash);
```

## Return Type

`DecodedContentHash | null`

Returns `null` for an unset content hash.
