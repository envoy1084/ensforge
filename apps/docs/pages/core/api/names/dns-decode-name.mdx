# dnsDecodeName

Decodes length-prefixed DNS labels into a normalized ENS name.

## Import

```ts
import { dnsDecodeName } from "@ensforge/core";
```

## Usage

```ts
const name = dnsDecodeName(encoded);
```

## Parameters

### encodedName

`Hex | DnsEncodedName`

DNS wire-format bytes.

## Return Type

`NormalizedName`
