# encodeContentHash

Encodes a supported content protocol and value into resolver content-hash bytes.

## Import

```ts
import { encodeContentHash } from "@ensforge/core";
```

## Usage

```ts
const contentHash = encodeContentHash({ protocol: "ipfs", value: cid });
```
