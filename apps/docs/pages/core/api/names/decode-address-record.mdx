# decodeAddressRecord

Decodes resolver address bytes into the human-readable form for a SLIP-44 coin type.

## Import

```ts
import { decodeAddressRecord } from "@ensforge/core";
```

## Usage

```ts
const address = decodeAddressRecord({ coinType: 60n, data });
```

## Return Type

`string | null`

Returns `null` for an unset record.
