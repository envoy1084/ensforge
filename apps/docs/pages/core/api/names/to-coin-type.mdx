# toCoinType

Converts an EVM chain ID to the corresponding ENSIP-11 coin type.

## Import

```ts
import { toCoinType } from "@ensforge/core";
```

## Usage

```ts
const coinType = toCoinType(8453);
```

<ReadActionDemo action="utilities.toCoinType" />

## Return Type

`CoinType`

Ethereum mainnet uses SLIP-44 coin type `60n`; other EVM chains use the ENSIP-11 namespace.
