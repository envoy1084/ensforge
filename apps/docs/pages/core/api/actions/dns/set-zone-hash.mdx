# setZoneHash

Sets zone hash for DNSSEC names and DNS resolver records.

## Import

```ts
import { setZoneHash } from "@ensforge/core";
```

## Usage

:::code-group

```ts [index.ts]
import { setZoneHash } from "@ensforge/core";
import { config } from "./config";

const result = await setZoneHash(config, {
  name: "example.eth",
  value: "https://example.com",
});
```
