# getSubnames

Lists direct indexed subnames of an ENS name.

## Import

```ts
import { getSubnames } from "@ensforge/core/indexer";
```

## Usage

:::code-group

```ts [index.ts]

const result = await getSubnames(config, {
  name: "example.eth",
  pageSize: 20,
```
