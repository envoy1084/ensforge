# getOrCreateResolver

Returns a compatible resolver or deploys one when required.

## Import

```ts
import { getOrCreateResolver } from "@ensforge/core";
```

## Usage

:::code-group

```ts [index.ts]

import { config } from "./config";

const result = await getOrCreateResolver(config, {
  name: "example.eth",
});
```
