# approveMigration

Approves migration for ENSv1 to ENSv2 migration.

## Import

```ts
import { approveMigration } from "@ensforge/core";
```

## Usage

:::code-group

```ts [index.ts]
import { approveMigration } from "@ensforge/core";
import { config } from "./config";

const result = await approveMigration(config, {
  name: "example.eth",
});
```

// [!include ~/snippets/core/config.ts]

## Parameters

```ts
import type { ApproveMigrationParameters } from "@ensforge/core";
```

### name

`string`

ENS name to operate on. ensforge normalizes it before hashing or contract interaction.

### approved

`boolean | undefined`

Whether the target should be approved.
