# revokeResolverRoles

Revokes resolver roles for approvals and scoped roles.

## Import

```ts
import { revokeResolverRoles } from "@ensforge/core";
```

## Usage

:::code-group

```ts [index.ts]
import { revokeResolverRoles } from "@ensforge/core";
import { config } from "./config";

const result = await revokeResolverRoles(config, {
  name: "example.eth",
  account: "value",
  record: {},
});
```

```ts [config.ts]
// [!include ~/snippets/core/config.ts]
```

:::

## Parameters

```ts
import type { ResolverRolesMutationParameters } from "@ensforge/core";
```

### name

`string`

ENS name to operate on. ensforge normalizes it before hashing or contract interaction.

### account

`string`

Account used to authorize this operation. Defaults to the account exposed by the resolved wallet client.

### record

`ResolverRecord`

Resolver record used by this operation.

### roles

`bigint | undefined`

Role bitmask to read, grant, or revoke.
