# extendSubnameExpiry

Extends subname expiry for wrapped names, expiries, and fuses.

## Import

```ts
import { extendSubnameExpiry } from "@ensforge/core";
```

## Usage

:::code-group

```ts [index.ts]
import { extendSubnameExpiry } from "@ensforge/core";
import { config } from "./config";

const result = await extendSubnameExpiry(config, {
  name: "example.eth",
  expiry: 2_000_000_000n,
});
```

```ts [config.ts]
// [!include ~/snippets/core/config.ts]
```

:::

## Parameters

```ts
import type { ExtendSubnameExpiryParameters } from "@ensforge/core";
```

### name

`string`

ENS name to operate on. ensforge normalizes it before hashing or contract interaction.

### expiry

`bigint`

Unix timestamp for the requested expiry.
