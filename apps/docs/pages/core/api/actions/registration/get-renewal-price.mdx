# getRenewalPrice

Gets renewal price for registration and renewal.

## Import

```ts
import { getRenewalPrice } from "@ensforge/core";
```

## Usage

:::code-group

```ts [index.ts]

const result = await getRenewalPrice(config, {
  name: "example.eth",
  duration: 365n * 24n * 60n * 60n,
});
```

## Parameters

```ts
type Parameters = Parameters<typeof getRenewalPrice>[1];
```

### name

`string`

ENS name to operate on. ensforge normalizes it before hashing or contract interaction.

### duration

`bigint`

Duration in seconds.

### blockNumber

`bigint | undefined`

Block number to read from. Cannot be combined with `blockTag`.

### blockTag

`"latest" | "earliest" | "pending" | "safe" | "finalized" | undefined`

Named block state to read from. Cannot be combined with `blockNumber`.

### paymentToken

`EthereumAddress | undefined`

ERC-20 token used when the registrar supports token payments.
