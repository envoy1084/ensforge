# Installation

::: code-group

```sh [pnpm]
pnpm add @ensforge/sdk effect@rc viem
```

```sh [npm]
npm install @ensforge/sdk effect@rc viem
```

```sh [yarn]
yarn add @ensforge/sdk effect@rc viem
```

```sh [bun]
bun add @ensforge/sdk effect@rc viem
```

:::

Install `wagmi` as well when you plan to construct the SDK from a Wagmi config.

```sh
pnpm add wagmi
```

The package is ESM-only and includes TypeScript declarations.
